## 🤖 Replit Prompt: Build “Growth CRM Agent” — ICP → Lead Sourcing → Campaigns (Email/LinkedIn) with Zapier Option

**Objective**
Create an AI-powered CRM agent that:

1. **Captures/infers ICP** (Ideal Customer Profile).
2. **Finds leads** (company + people) and **enriches contacts** (email, LinkedIn, role).
3. **Builds & sends cold outreach campaigns** (email + LinkedIn DM; optional groups/communities).
4. Uses **Zapier integrations** (or native APIs) for delivery, tracking, and CRM sync.

> ⚠️ **Compliance & TOS**: Do not scrape sites that prohibit it (e.g., LinkedIn’s TOS). Use **user-authorized APIs/partners** (Apollo, Clearbit, People Data Labs, Hunter, Clay, Phantombuster, Google CSE/SerpAPI). Include **opt-out & throttling**; comply with **CAN-SPAM/GDPR**.

### 1) ICP Builder (AI + Form)

**Flow**

* Left sidebar **ICP Wizard** (AI chat + structured form).
* Collect or infer:

  * Industries, geos, company size, tech stack, seniority/roles, pains, triggers, buying window, budget band.
* Output a **typed JSON ICP** and a short **narrative** (value props, objections, proof).

**Deliverables**

* `icp.json` schema (see below).
* “Save ICP” → persists to CRM.
* “Generate Target Query” → string/filters usable by data providers & Google CSE (e.g., `site:crunchbase.com fintech AND "Head of Operations" "San Francisco"`).

**ICP Schema**

```json
{
  "name": "Fintech-Seed-US",

  "personas": [{ "title": ["Head of Ops","COO"], "seniority": ["Director","VP"], "functions": ["Operations"] }],
  "pain_points": ["manual reconciliations","expensive chargebacks"],
  "triggers": ["hiring ops mgr","Series A announcement"],
  "value_props": ["reduce ops cost 30%","speed to revenue"],
  "keywords": ["payment ops", "chargebacks", "reconciliation"]
}
```

### 2) Lead Sourcing & Enrichment (compliant)

**Integrations (choose any)**

* **Company/People Data**: Apollo, Clearbit, People Data Labs, Crunchbase API.
* **Email Discovery/Verification**: Hunter, Snov, NeverBounce, Zerobounce.
* **Search**: Google Custom Search / SerpAPI (for public pages, blogs, press).

**Flow**

* “Find Leads” → uses ICP filters to query providers.
* **Enrich** each record (role, LinkedIn URL, company domain, email guess, verification result, phone if available).
* **Validate** emails (NeverBounce etc.).
* **Dedupe** by email/domain + persona.
* Present **Lead Table** with score.

**Lead Object**


**UI**

* Filters: persona, industry, geo, verification status, score.
* Bulk actions: add to list, export CSV, push to campaign.

### 3) Campaign Builder (Email + LinkedIn)

**Channels**

* **Email** (native SMTP or via Gmail/Outlook through **Zapier**; or Mailgun/Resend).
* **LinkedIn**: export tasks/CSV for manual send OR send via **user-owned** Phantombuster/Dripify/Clay actions through Zapier/Make.

**Campaign Features**

* **Sequences**: Day 0, 3, 7 with branch on reply/bounce.
* **Personalization**: variables & AI snippets (`{{firstName}}`, `{{recent_post}}`) + research step (scrape **company blog only** or use provider summaries).
* **Safety**: daily send limits, warm-up pacing, random delays, time-of-day windows, auto-unsubscribe footer for email.

**Tracking**

* Status per recipient: queued/sent/open/click/replied/bounced.
* Link tracking domain (optional).
* **Opt-out** management across the CRM.

**Campaign Schema**

```json
{
  "name": "Fintech-COO-Outreach-SetA",
  "from": {"name":"Naveen","email":"naveen@requisor.io"},
  "steps":[
    {"dayOffset":0,"channel":"email","templateId":"t1"},
    {"dayOffset":3,"channel":"email","templateId":"t2","ifNoReply":true},
    {"dayOffset":6,"channel":"linkedin","action":"connection_request","note":"short"}
  ],
  "audienceListId":"list_abc",
  "limits":{"maxPerDay":60,"window":"09:00-17:00","timezone":"America/Chicago"}
}
```

**Templates**

* Library with AI assistant: generate 3 variants (A/B), tone (direct/helpful/humorous), 100–130 words max, one CTA.
* Snippets: case-study proof, value prop, soft CTA, PS lines.
